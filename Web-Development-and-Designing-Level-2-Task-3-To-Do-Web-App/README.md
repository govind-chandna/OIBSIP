# To-Do Web App

## About the Project

This is a simple and responsive To-Do Web Application built using HTML, CSS, and JavaScript.

It helps users manage their daily tasks by adding, editing, completing, and deleting tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Display total tasks
- Display pending tasks
- Display completed tasks
- Save tasks using LocalStorage
- Tasks remain saved after refreshing the page
- Responsive design for mobile and desktop
- Press Enter to add a task
- Empty input validation
