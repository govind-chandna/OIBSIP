# Calculator - Oasis Infobyte Internship

## Project Overview

This is a responsive calculator web application developed as part of the Oasis Infobyte Web Development and Designing Internship.

The calculator performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear button
- Backspace button
- Equals button
- Division by zero error handling
- Responsive and clean user interface
- CSS Grid layout
- JavaScript event listeners
