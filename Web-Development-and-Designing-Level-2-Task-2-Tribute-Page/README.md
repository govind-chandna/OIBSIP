# Tribute Page - Dr. A.P.J. Abdul Kalam

## About the Project

This is a responsive tribute page dedicated to Dr. A.P.J. Abdul Kalam,
one of India's most respected scientists and former President.

The page highlights his life, achievements and inspirational message.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive design
- Dr. A.P.J. Abdul Kalam's image
- Introduction section
- Important achievements timeline
- Inspirational quote
- Multiple background sections
- Different font styles
- Mobile-friendly layout
